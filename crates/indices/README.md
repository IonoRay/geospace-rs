# IonoRay indices

Independent Kp/ap/Ap/F10.7, Dst/AE and IRI index collection with raw CAS identity and coverage audits.
`main` has no bundled snapshots. `cache-snapshots` and an explicit build-time `IONORAY_CACHE_ROOT` can supply pinned optional snapshots.
Ensure reuses complete local coverage, Refresh checks upstream, Offline sends no HTTP request and reports residual gaps.

Original software uses MIT OR Apache-2.0. GFZ data uses CC BY 4.0 except the included SN (CC BY-NC 4.0); preserve GFZ-NOTICE.txt. IRI data follows IRI-LICENSE.txt. See THIRD_PARTY_NOTICES.md; downloaded data is not relicensed as IonoRay software.
